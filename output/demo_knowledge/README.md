# 模拟财务资料

5份资料均已导入本项目的 `knowledge/uploads/`。内容为手工构造的模拟数据，各文件都明显标注模拟用途。它们作为知识资料检索，不会写入或替换账单CSV，也不会触发真实扣款、转存或报销。

| 文件 | 内容与可核对数字 |
|---|---|
| 模拟_2026年9月收支报告.pdf | 2页：收入15000元、支出8600元、结余6400元；支出预算9000元、剩余额度400元 |
| 模拟_差旅报销规则与案例.pdf | 2页：自拟规则和案例，铁路186.50、住宿520、出租车80、餐补120，合计906.50元 |
| 模拟_2026年9月财务复盘.pptx | 4页：收支概览、分类支出、储备目标和10月行动计划，包含原生表格和备注 |
| 模拟_2026年10月12日消费记录.png | 中文OCR示例：23.00+12.00+89.90=124.90元 |
| 模拟_2026年10月订阅清单.jpg | 中文OCR示例：18.00+12.00+49.00=79.00元，并列出下次扣款日期 |

在工作台的「知识库 · 导入资料」中可查看和下载已入库原件。可以直接提问：

1. 根据模拟的2026年9月收支报告，收入、总支出和月结余分别是多少？
2. 模拟差旅报销案例的合计金额是多少，住宿报销金额是多少？
3. 模拟10月行动计划中购物预算如何调整，每月储备转存是多少？
4. 根据模拟的2026年10月12日消费记录，当日支出合计多少？
5. 模拟2026年10月订阅清单的月费合计是多少，云存储何时扣款？

`demo_cases.json`保存问题、参考答案、原文件、检索位置和关键数值校验结果。这5个问题只用于演示冒烟，不代表总体检索正确率；发现的一个多月份长查询召回问题也保留在该文件中。解析时已将PPT同页原生文本框合并，避免标签和数值分别成为碎片。

加入新资料会改变BM25词频及排序，旧12篇MD的历史评测数字不能直接代表扩充后知识库。历史回归测试固定使用原顶层MD语料，新增模拟资料按自己的问题与原文证据单独核验。

PDF和PPTX已经渲染核对；图片文字与关键金额已通过本地OCR核对。10月图片与9月汇总属于不同月份，不合并统计。储备目标和报销规则均为本演示自拟，不代表真实制度或理财建议。
