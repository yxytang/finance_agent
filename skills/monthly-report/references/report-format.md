# 月度报告的格式

## 骨架

```markdown
## 2026-07 收支

合计 **8,234.56**，共 87 笔。

### 按类目

| 类目 | 金额 | 笔数 |
|---|---|---|
| 房租 | 3,250.00 | 1 |
| 餐饮外卖 | 1,204.30 | 24 |
| … | | |

### 值得看一眼的

- …
```

## 几条硬要求

**金额一律 `1,234.56`** —— 千分位、两位小数。不要写 `1234.5`。

**没数据就说没数据。** 「这个月餐饮 0.00」和「这个月没有餐饮记录」是两句不同
的话，前者暗示花过但金额为零。查到 0 笔时，先想一下是真的没有还是筛选条件
写错了，说不清就问用户。

**环比要把两个原始数字写出来。** 「比上月多 1,200.34（6 月 7,034.22 →
7 月 8,234.56）」比「+17.1%」有用得多 —— 前者用户能自己验算，后者不能。

**笔数也要给。** 合计 1,204.30 是「点了 24 次外卖」还是「吃了 3 顿贵的」，
对用户是两件完全不同的事。

**不要加客套。** 不加「希望对您有帮助」「祝您理财顺利」。
